Đưa code lên GitHub

GitHub lưu trữ mã và lịch sử thay đổi. Với trang HTML tĩnh, có thể dùng GitHub Pages hoặc Cloudflare Pages để xuất bản.

  1. Tạo repository mới, chọn quyền truy cập phù hợp; không đưa bí mật vào repository dù repository riêng.
  2. Tải các file website lên cùng thư mục gốc, nơi có index.html.
  3. Commit với mô tả thay đổi rõ, ví dụ “Thêm bài hướng dẫn AI tạo sinh”.
  4. Bật GitHub Pages hoặc kết nối repo với Cloudflare Pages theo hướng dẫn chính thức.
  5. Mở đường dẫn xuất bản trên máy tính và điện thoại; kiểm tra trang con, CSS, JS và liên kết.
  6. Khi cập nhật: chỉnh file → commit → chờ deploy → kiểm tra lại. Git lưu lịch sử, nên xóa file không đồng nghĩa xóa bí mật khỏi mọi lịch sử.

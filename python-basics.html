06 · Python nhập môn

Biến, điều kiện, vòng lặp và hàm

Python thường được dùng để học lập trình, xử lý dữ liệu và làm thử nghiệm AI. Hãy chạy các ví dụ trong môi trường Python đáng tin cậy do giáo viên hướng dẫn.

hello.py Python
name = input("Tên bạn là gì? ").strip()

if name:
    print(f"Xin chào, {name}!")
else:
    print("Xin chào bạn!")

scores = [8, 9, 7]
average = sum(scores) / len(scores)
print("Điểm trung bình mẫu:", average)
  • Biến: tên gắn với một giá trị, ví dụ name.
  • Điều kiện: if/else chọn nhánh.
  • Vòng lặp: lặp qua dữ liệu; tránh vòng lặp vô hạn.
  • Hàm: gom thao tác có tên để dùng lại.

Ví dụ chỉ dùng dữ liệu giả. Không nhập/xử lý danh sách tên, điểm thật hay thông tin nhận dạng của bạn học nếu chưa được phép.

Vòng lặp, hàm và dữ liệu có cấu trúc

Chạy ví dụ bằng Python cài từ nguồn chính thức hoặc môi trường lớp học. Tạo file club_tasks.py, lưu và chạy python club_tasks.py (một số máy Windows dùng py club_tasks.py).

1. Lặp qua danh sách và thống kê

club_tasks.py Python
tasks = ["Viết câu hỏi FAQ", "Kiểm thử bot", "Cập nhật README"]

for number, task in enumerate(tasks, start=1):
    print(f"{number}. {task}")

print("Tổng số việc:", len(tasks))

2. Viết hàm có đầu vào và đầu ra

Tách hàm để tái sử dụng Python
def count_completed(statuses):
    """Đếm số mục có trạng thái hoàn tất."""
    return sum(1 for status in statuses if status == "done")

sample = ["done", "todo", "done", "todo"]
print(count_completed(sample))  # 2

3. Thử bài tập

  • Thêm task thứ tư vào danh sách và quan sát output.
  • Viết hàm nhận điểm 0–10; nếu ngoài phạm vi, trả thông báo lỗi thay vì tính trung bình.
  • Đếm số việc theo nhóm trong một dictionary giả lập.
  • Viết test tay: danh sách rỗng, dữ liệu hợp lệ, dữ liệu sai kiểu.
Không dùng thông tin tên/lớp/điểm thật của học sinh làm bộ dữ liệu. Khi nhập dữ liệu từ người dùng, cần kiểm tra kiểu và phạm vi; không mặc định đầu vào luôn đúng.

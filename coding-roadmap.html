Lộ trình Coding Lab 8 buổi

Kế hoạch học từng buổi từ HTML đến GitHub và AI coding.

Chương trình 8 buổi: từ trang trắng đến sản phẩm

Buổi 1 — HTML

Tạo cấu trúc trang CLB; tiêu đề, liên kết, ảnh có alt text. Sản phẩm: trang một màn hình.

Buổi 2 — CSS

Màu, chữ, khoảng cách, Flexbox/Grid và responsive. Sản phẩm: giao diện desktop + mobile.

Buổi 3 — JavaScript

Biến, hàm, điều kiện, sự kiện, DOM. Sản phẩm: nút tương tác và bộ lọc.

Buổi 4 — Dữ liệu trình duyệt

Mảng, đối tượng, JSON và localStorage. Sản phẩm: taskboard cá nhân.

Buổi 5 — Tư duy kiểm thử

Ca kiểm thử, lỗi biên, bàn phím, mobile và Console. Sản phẩm: checklist QA.

Buổi 6 — Python

Kiểu dữ liệu, điều kiện, vòng lặp, hàm. Sản phẩm: công cụ dòng lệnh xử lý dữ liệu giả.

Buổi 7 — Git & GitHub

Commit, lịch sử, README, Pages. Sản phẩm: dự án có thể xem lại và triển khai.

Buổi 8 — AI hỗ trợ code

Viết prompt, duyệt diff, test, không lộ key. Sản phẩm: cải tiến nhỏ có giải thích.

Mỗi buổi có thể 60–90 phút; điều chỉnh theo giáo viên phụ trách, lịch thật và thiết bị có sẵn.
